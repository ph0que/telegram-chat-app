# План выполнения проекта: Telegram Chat App

## Описание
Разработка аналога Telegram-чата с фронтенд на React + TypeScript, бэкенд на Python + FastAPI и развёртывание на Vercel и Render.

## Этапы реализации

### 1. Дизайн (UI/UX)
- Создание макета чата в HTML/CSS
- Основные элементы:
  - Область сообщений с прокруткой
  - Строка ввода сообщения
  - Шапка с именем контакта
  - Временные метки сообщений
  - Визуальное различие между своими и чужими сообщениями
- Адаптивный дизайн для мобильных устройств

### 2. Фронтенд (React + TypeScript + Tailwind CSS)
- Инициализация проекта с Vite
- Создание компонентов:
  - `ChatPage` - главная страница
  - `MessageList` - список сообщений
  - `MessageInput` - поле ввода
  - `MessageItem` - отдельное сообщение
- Управление состоянием с React hooks (useState, useEffect)
- API интеграция (fetch или axios)
- Динамическая загрузка сообщений с бэкенда

### 3. Бэкенд (Python + FastAPI)
- Инициализация FastAPI приложения
- REST API endpoints:
  - `GET /messages` - получить список сообщений
  - `POST /messages` - отправить новое сообщение
- Хранилище данных в памяти (список сообщений)
- CORS поддержка для кросс-доменных запросов
- Структура сообщения:
  ```
  {
    "id": 1,
    "text": "Hello",
    "fromMe": true,
    "timestamp": "2024-12-15T01:30:00"
  }
  ```

### 4. Интеграция фронт-бэк
- Подключение фронтенда к API бэкенда
- Отправка POST запроса при отправке сообщения
- Получение GET запросом истории сообщений при загрузке
- Обработка ошибок и loading состояний

### 5. Деплой
- Фронтенд на Vercel (GitHub интеграция)
- Бэкенд на Render (GitHub интеграция)
- Настройка переменных окружения
- Проверка работоспособности на боевом сервере

### 6. Саморевью и документация
- Описание выполнённой работы
- Анализ решений и сложностей
- Перечисление недоработок и идей для улучшения
- Оценка по 10-балльной шкале

## Примерный график
- Дизайн: 1 час
- Фронтенд: 2-3 часа
- Бэкенд: 1-2 часа
- Интеграция: 1 час
- Деплой: 1 час
- Саморевью: 30 минут

**Итого: ~6-8 часов**

## Технический стек
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Backend**: Python 3.10+, FastAPI, Uvicorn
- **Хостинг**: Vercel (frontend), Render (backend)
- **Контроль версий**: Git, GitHub

## Ключевые точки внимания
- Чистая история коммитов с понятными сообщениями
- Аккуратный UI без пиксель-перфекта, но визуально приятный
- Простой и понятный API
- Работающее демо на публичных URL'ах
